## 2024-05-24 - Fix Scroll Wheel Behavior in WheelSelector
**Learning:** React state updates triggering programmatic scrolls (`scrollTo` with `behavior: 'smooth'`) often conflict with continuous user scroll events (e.g., from trackpads or scroll wheels). This results in a fight between manual and programmatic scrolling, causing jitter, stuttering, and wild jumps, especially when combined with infinite looping logic that artificially alters `scrollLeft` position.
**Action:** Implemented a robust `isUserScrolling` ref to distinguish between user-initiated and programmatic scrolls. Suppress programmatic re-centering (`useEffect`) while the user is actively scrolling, and suspend infinite looping calculations (`scrollLeft += totalWidth`) during smooth scrolling to prevent snapping conflicts. Always debounce the reset of the `isUserScrolling` flag to handle continuous wheel events cleanly.
